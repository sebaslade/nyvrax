# Security Policy

Nyvrax is security tooling. Vulnerabilities affecting Nyvrax itself should not be disclosed through a public issue when doing so would expose users to unnecessary risk.

Please use the repository's private security reporting mechanism when available.

Reports should include:

- affected version or commit;
- reproduction steps;
- security impact;
- relevant environment information;
- proposed remediation, if known.

Do not include real credentials, production secrets, or sensitive third-party data in reports.
